# CampusLink 🎓

Plus qu'un match, une connexion.

CampusLink est une application mobile destinée aux étudiants majeurs qui souhaitent créer des connexions authentiques basées sur leurs passions, leurs ambitions et leur vie étudiante.

## Fonctionnalités du MVP

- Création de compte
- Vérification de l'âge
- Profil étudiant
- Recherche de profils
- Matchs
- Messagerie privée
- Signalement et blocage
